About

Building products end to end

I study Computer Science & Engineering at East West University, Bangladesh. I'm interested in software engineering and UI/UX, and enjoy turning real problems into useful apps. I like the whole loop: understand the need, design the interface, then build and ship the product. Long term, I'm aiming to build products of my own through tech entrepreneurship.

  1. 01Understand

    Start from the real problem and the people who have it.

  2. 02Design

    Shape the interface before writing the code behind it.

  3. 03Build

    Front end, API and database, kept consistent end to end.

  4. 04Ship

    Release it, then learn from how it is actually used.
